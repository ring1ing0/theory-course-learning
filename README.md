# Theory Course Learning

大学理论课学习技能：以教材为依据，讲清原理、条件与推导，通过低输入量练习验证理解，并保留可跨会话恢复的学习进度。

## 主要能力

- **教材驱动**：优先沿用教材与讲义的定义、符号和范围。
- **完整讲授**：按内容组织推导、图示、过程追踪和完整例题。
- **低输入量练习**：以选择、判断和关键步骤短答减轻誊写负担。
- **按证据推进**：区分已讲授与已掌握，针对实质错误修复。
- **续学与复习**：保留断点、待答题和真实作答，按需安排关键目标的延迟复习。
- **节奏管理**：按大节点估时，并依据实际有效学习时间调整。

## 使用方式

将本仓库作为名为 `theory-course-learning` 的技能目录放入所用助手的技能目录，并保留以下文件结构。

在对话中提供教材或讲义、当前学习位置与目标，例如：

> 使用 theory-course-learning，按这份教材帮我学习计算机组成原理。从存储系统开始，讲清机制并给完整例题，练习以选择和判断为主。

续学时可指定课程工作区并说“继续学习”。单题辅导可以直接给题目，无须先建立完整课程档案。

## 文件结构

```text
theory-course-learning/
├── SKILL.md                 # 主技能指令
├── references/
│   ├── depth.md             # 目标深度、讲授组织与教学衔接
│   ├── pacing.md            # 时间预算与节奏校准
│   └── progress.md          # 进度、作答证据与跨会话恢复
└── README.md
```

课程教材、个人作答与进度记录保存在各自课程工作区，不属于技能本体。
