# 目标深度与教学衔接

在用户提供目标试题、评估深度、改变学习目标，或出现反复混淆/节奏反馈时读取。普通续学复用已记录的对应关系，不每轮重建计划。

## 按内容组织讲授

按当前问题选取解释方式，下表是常见内容的默认组织建议；混合主题可以组合，形式证明等其他主题仍按其推理需要展开，不强套分类或固定步骤。

| 内容 | 讲授主线 | 完整示范应包含什么 |
|---|---|---|
| 概念、分类、结构或标准 | 解决什么问题、定义与边界、分类依据、必要结构图与对比例子 | 一个能说明区别、设计理由或适用条件的情境；公式少不等于省略因果解释 |
| 数值表示、运算、算法、性能计算 | 必要定义与表示、规则或公式的推导、完整演算、边界与易错处 | 位宽、符号、单位、初始状态、每轮关键变化和结果核对；不只列公式与最终答案 |
| 硬件、电路、存储器、数据通路 | 完整任务、框图/连线图、信号或数据追踪、由条件推出接法或计算 | 在同一图上标明信号方向、位宽与控制条件，追踪一次真实读写/执行；计算与结构对应 |
| I/O、中断、DMA等交互流程 | 参与者与控制权、流程图或时序图、完整情境、必要开销计算 | 谁发起、谁响应、何时交接、谁占用CPU/总线及完成条件；公式中的时间对应实际阶段 |

同一实例优先贯穿概念、图与计算，避免频繁换数字、芯片规格或表示法增加额外负担。必要的新符号和表示转换先示范；学生已有明确证据的步骤可压缩。对初学关键方法，教师完整示范之后再安排少量未见应用，不把连续填空串当作完整示范。

图示用于解释结构和过程：静态关系用清晰的框图/连线图，时序用时间轴，迭代用状态表；交互模拟仅在改变条件确实帮助理解时使用。图中的标注要与后续算式和题目一致，不为绘图另起工具部署流程。

用户提供的视频结构可以作为讲法参考。未实际核验的时长和比例保持为用户给出的估计；图示、推导与例题往往重叠，不能直接当互斥占比相加。按内容检查哪些环节缺失，不设跨章节固定比例，也不把视频播放时长当作有效自学时长。

## 从目标反推深度

抽查与当前及后续核心模块有关的代表题，区分题干核验、独立求解与答案核验。标注来源位置；题干/解析矛盾、OCR 失真或回忆版本不确定时暂不用于正式计分。可先据清楚的题目结构判断能力需求，但不宣称已验证答案。

为重要目标保留简短对应关系：目标题型 → 必要前置 → 学生应能自己完成的推导/机制链 → 覆盖这些要求的证据 → 尚缺范围。不为每个知识点建矩阵，也不要求穷尽所有历年题。非考试课程可用证明、设计、解释现象等实际成果作为目标。

区分：辨认术语、直接应用、条件变化、跨知识点综合。它们是证据能力范围，不是强制四阶段流水线。低输入题也能验证复杂判断；当目标需要构造、计算链或证明时，需有学生自行产生关键步骤的证据。

题目“从没见过”只说明新颖性；只改数字、紧跟例题结构或题干列全中间步骤，仍可能只是直接应用。基础任务答对不能替代目标难度验收，也不能把未教过的高级内容记成学生弱项。

## 衔接模型，减少概念跳跃

在换层次、对象、表示法或条件时说明：当前讨论哪个对象、各量的单位/含义、旧结论依赖什么假设、新条件怎样改变它。用一个完整实例追踪到结果，再让学生处理需要迁移的一处变化。

例如计算机组成中的整机字节地址、芯片内部地址、数据通路宽度不应直接套同一个容量式；先说明每种地址选中什么、每次传送什么。数学中从标量改为矩阵也需指出原运算规律哪些仍成立。例子仅示意衔接方式，不把特定学科流程强加到所有课程。

用户反馈“稍快但能接受”：优先在依赖密集处放慢，减少新概念同时出现；保留其他已理解内容的推进速度。反馈“混乱”或同类错误再现：暂停叠加新模型，先补具体过程、图或单位关系。不能只把同型题数字越改越小，然后把一次正确当成全部修复。

## 验证和推进

- 先区分教材定义、标准约定、数学推导、实际机制；解释约定的作用，不声称所有约定都能从前提唯一推出。
- 概念辨认足够时，避免堆叠同层次题；讲授、示例与练习围绕一个完整问题组织。
- 关键目标前置齐备时，给少量匹配目标难度的任务；可拆为关键一步或几个关联小问，减轻输入但保留学生独立选择方法的部分。
- 修复后分开记录“这一步现在能做”和“整体迁移尚未验证”。证据不足可继续不依赖该缺口的新内容，不设置无限补考或全课阻塞。
- 用户要求看解答或跳过时照办；保留未验证范围，不虚构作答或达标。

发出练习前快速检查：完整机制是否已解释，题目使用的表示方法是否教过，是否留有学生真正需要作出的判断。若先前题目暴露这些教学缺失，在进度中记录待补讲范围，补完再验证；解释本身不能升级掌握度。

## 计划与时间取舍

新目标若要求独立完成综合题，旧计划中相关内容的“仅概念了解”不再足够。保留可选细节，补上对应推导与应用；需要更多时间时列出可调整的时长或范围，不承诺原时长必然够用。不能按教材行数、聊了几轮或做了几道选择题判断实际学习量。

核心导入完成、章节所列目标讲完、目标难度验收通过分别报告；计划周次只定位内容。计划与进度并存时指定一个周次安排来源，另一份作为同步视图；实际断点与待答题以最新课程记录为准。
